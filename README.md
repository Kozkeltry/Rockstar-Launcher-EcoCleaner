# Rockstar-Launcher-EcoCleaner

A lightweight, open-source C++ utility designed to safely clear the Rockstar Games Launcher download cache.

## 🛠️ What it does
* **Clears Corrupted Cache:** Safely deletes the accumulation of temporary files in the `download_cache` directory.
* **Prevents Stutters:** Helps resolve launcher update loops and minor performance drops caused by corrupted cache files.
* **Safe Re-creation:** Automatically re-creates the empty folder structure to ensure the launcher boots up smoothly.

## 🚀 How to use
1. **Close** the Rockstar Games Launcher completely.
2. Run the `RockstarCleaner.exe`.
3. Done!
